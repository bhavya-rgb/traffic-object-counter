# Output Video

This folder contains the processed output video generated by the traffic object detection and counting system.

The output video includes:

* Vehicle bounding boxes
* Vehicle class labels
* Tracking IDs
* Detection confidence scores
* Vehicle counting line
* Vehicle counts

## Demo Video

https://drive.google.com/file/d/1cObml-pPXFII8Dml85tgg3hiJmy37m5m/view?usp=drive_link

The output video is generated by running:

```bash
python main.py
```

The generated file is saved as:

```text
output/result.mp4
```
