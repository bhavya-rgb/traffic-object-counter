# 🎥 Demo Video

This section contains the demonstration video of the Traffic Object Detection and Counting project.

The demo shows the system detecting and tracking vehicles in a traffic video and displaying the vehicle counts.

## Demo

https://drive.google.com/file/d/1cObml-pPXFII8Dml85tgg3hiJmy37m5m/view?usp=drive_link

The demo video demonstrates:

* 🚗 Car detection
* 🚌 Bus detection
* 🏍️ Bike/Motorcycle detection attempt
* 🎯 Vehicle tracking
* 🔴 Virtual counting line
* 📊 Vehicle counting

## Output

The processed video is generated using:

```bash
python main.py
```

and saved as:

```text
output/result.mp4
```
